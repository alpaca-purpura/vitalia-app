# @luana/ui-kit

**Version:** 0.0.1-alpha  
**Lift origin:** `AISALESHT/frontend/src/components/ui/`  
**Lift commit:** `3282768` (feat(luana-ts-batch2): lift @luana/ui-kit, @luana/api-client, @luana/schemas)

## Overview

Shadcn/ui-based primitive component library. 43 components covering layout,
forms, feedback, navigation, and data display. Tailwind CSS + `cn()` utility.

## Key exports

Barrel (`"."`) re-exports all components: `Button`, `Input`, `Select`,
`Dialog`, `Sheet`, `Popover`, `Tooltip`, `Badge`, `Card`, `Table`,
`Tabs`, `Form`, `Checkbox`, `Switch`, `Textarea`, `Avatar`, `Skeleton`,
`Separator`, `ScrollArea`, `DropdownMenu`, `Label`, `InlineEditable`,
and more. See `src/index.ts` for the complete list.
