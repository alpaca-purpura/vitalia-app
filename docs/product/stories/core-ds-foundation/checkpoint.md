## Src bugs encontrados durante T-2 — ✅ RESUELTOS (Chris ratificó fixearlos in-place 2026-06-22 · "no podemos tener bugs en el ui-kit")

   - ★ **Mismo bug-class encontrado + arreglado en 4 archivos más** (grep exhaustivo — el smoke NO los veía, breakage sutil de animación/tooltip): `popover.tsx` (`origin-[--radix-...]`), `select.tsx` (`max-h-` + `origin-`), `dropdown-menu.tsx` (`origin-` ×2), `chart.tsx` (`border-[--color-border] bg-[--color-bg]` del tooltip). Todos `[--x]` → `(--x)`. (T-3 drift-lint `no-arbitrary-value` los hubiera cazado; ya no quedan bare-var en `src/`.)
2. ✅ **`src/timezone-select.tsx` — tsc** `Intl.supportedValuesOf` requería lib ES2022. **Fix:** `tsconfig.json` `target`/`lib` ES2020 → ES2022. Resuelve también el `any` implícito del `.map` (ahora `supportedValuesOf` tipa `string[]`).
