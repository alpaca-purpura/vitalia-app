## [0.1.0] — 2026-05-15

### Agregado
- Lanzamiento inicial de Vitalia en la plataforma Luana.
- Sistema de reservas prepagadas para clínicas médicas, dentales y estéticas.
- Historial médico de pacientes con privacidad HIPAA-lite.
- Seguimiento post-tratamiento automatizado via canales de mensajería.
- Copilot IA para asistencia al equipo médico y comunicación con pacientes.
- Integración con Clerk para autenticación multitenant.
- Integración con MercadoPago para pagos de reservas en mercados LatAm.
- Sales Agent para calificación y agendamiento de consultas.
