## 🔴 Críticos (rompen el flujo)

- **L1 · Detalle del turno = 500 (drawer muerto).** Clic en CUALQUIER slot → `GET /api/v1/scheduling/appointments/{id}`
  **500**. Causa (traceback BE, `agenda_router.py:456` `AppointmentDetailDTO.model_validate(detail)`):
  **3 campos faltantes** — `doctor_label`, `payments.0.payment_id` (el dict trae `id`), `payments.0.amount_cents`
  (trae `amount`). → toda la cadena **detalle → cobrar saldo → emitir comprobante fiscal = INALCANZABLE**.
  Bug BE latente (nunca golpeado con 0 citas / 0 pagos; lo destapó el seed). Root: el service arma el dict con
  nombres de modelo (`id`/`amount`) en vez de los del DTO (`payment_id`/`amount_cents`) y **no resuelve `doctor_label`**.
  **(NUEVO — no estaba en D1-D8. Es el más grave.)**

## 🟠 Altos (la agenda luce rota con data real)
