- **ClinicAccountService** (NEW application/clinic_account_service.py): orchestrates GET account, PATCH account (with RBAC gate + validators + transaction + audit sync), GET specialty catalog, GET DPO reference.
- **account_router** (NEW api/account_router.py): 4 routes (GET/PATCH /account, GET /account/specialties-catalog, GET /account/dpo). Bearer + X-Tenant-ID. response_model mandatory on all.

### audit (CONSUME)
- **AsyncAuditWriter.write** (audit_writer.py): sync write to vitalia_audit_log. Signature: `write_audit_log_sync(db: Session, tenant_id: str, clinic_id: str, user_id: str, action: str, resource_type: str, resource_id: str, payload: dict | None, from_ip: str | None, user_agent: str)`. Called SYNC pre-response for clinic.account.updated action. Payload sanitized (PII removal); clinic identity fields (name, fiscal_id, email) logged, not PHI.

### _shared (NEW)
- **fiscal_id_validator.py** (NEW validation/): validates AR CUIT (11-digit + DV mod-11), PE RUC (11-digit), MX RFC (12-13 alfanum), CL/CO NIT (variable), UY RUT (12-digit). Country rules dict. Raises `FiscalIdValidationError` (field + message Spanish neutro) if invalid. Unsupported countries degrade to freetext (no block).
- **specialty_catalog.py** (NEW catalogs/): `SPECIALTY_CATALOG: dict[str, list[str]]` per country (AR/PE/MX/CL/CO/UY). Function `validate_specialties(specialties: list[str], country: str) → None` (raise if outside catalog). Maps: FISCAL_ID_LABEL_BY_COUNTRY (CUIT/RUC/RFC/NIT/RUT), LANGUAGE_BY_COUNTRY (derived).

### brand_studio (EXTEND reference)
