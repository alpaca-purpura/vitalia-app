## Spec Pattern Decisions

- **a11y-smoke.spec.ts:** usa `AxeBuilder.exclude("iframe")` para ignorar iframe Clerk (bot-detection widget interno que puede trigger false-positives). Filtra solo `critical` y `serious` (warnings y minor no bloquean).
- **mobile-smoke.spec.ts:** helper `assertNoHorizontalScroll` con 1px tolerancia para sub-pixel rendering. Helper `assertPrimaryButtonTappable` busca botón por role+name (no hardcoded selector). Dashboard test usa `authedPage` fixture.
- **visual-smoke.spec.ts:** inyecta `animation-duration: 0ms` para screenshots determinísticos. Hace mask de elementos dinámicos (captcha clerk, avatares, timestamps). `maxDiffPixelRatio: 0.2` = 20% tolerancia para variaciones de fuente entre OS.
- **playwright_console_network_audit.sh:** allowlist 401 (pre-auth), ignora ClerkJS/DevTools/favicon errors. Parsea trace.zip vía `unzip + jq`. Falla con exit code 1 si encuentra errores fuera del allowlist.
