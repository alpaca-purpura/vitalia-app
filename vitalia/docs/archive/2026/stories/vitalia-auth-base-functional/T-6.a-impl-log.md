## § Hallazgos de contexto (pre-implementación)

### 1. Spec file naming mismatch

**Problema:** 06-tickets.yaml define archivos sin sufijo `.smoke` (e.g., `sign-in-redirect.spec.ts`), pero el smoke project en `playwright.config.ts` solo matchea `*.smoke.spec.ts`.

**Solución aplicada:** `playwright.config.ts` smoke project actualizado con array de testMatch incluyendo los tres directorios nuevos:
```typescript
testMatch: [
  /.*\.smoke\.spec\.ts/,
  /.*\/e2e\/auth\/.*\.spec\.ts/,
  /.*\/e2e\/dashboard\/.*\.spec\.ts/,
  /.*\/e2e\/admin\/.*\.spec\.ts/,
]
```

### 2. @clerk/testing no instalado

**Estado:** `package.json` solo tiene `@clerk/nextjs@6.36.8`. `@clerk/testing` NO instalado.

**Impacto:** `setupClerkTestingToken` no disponible. `auth.fixture.ts` ya maneja esto con graceful fallback (try/catch dynamic import).

**Decision:** Los specs que usan `authedPage` (dashboard/welcome.spec.ts) confían en el fallback de auth.fixture.ts. Los specs de auth (sign-in-redirect, sign-in-form) usan `@playwright/test` directo sin auth.

### 3. Admin Streamlit en puerto separado 8501

**Estado:** Admin panel es un proceso separado (Streamlit). No arranca con `make dev-vitalia` standard.

**Decision:** `tenants-users.spec.ts` usa `E2E_ADMIN_BASE_URL` (default `http://localhost:8501`). Password vía `VITALIA_ADMIN_PASSWORD` env var, nunca hardcodeada. Tests usan `test.skip()` + mensaje accionable si el admin no está disponible.

### 4. `scripts/e2e-preflight.sh` no existe

**Estado:** `bash scripts/e2e-preflight.sh` retorna "No existe el archivo". Script no fue creado aún.

**Impacto:** Preflight check no puede ejecutarse. Documentado como gate bloqueado.
