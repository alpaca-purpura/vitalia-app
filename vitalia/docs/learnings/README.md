# Vitalia — learnings

Insights brand-local. Cada `{date}-{slug}.md` documenta:
- **Qué aprendimos** (1-2 párrafos)
- **Origen** (story/outcome/incident)
- **Promotable** flag: `yes | candidate | no`
- **Why:** razón behind
- **How to apply:** cuándo aplicar

Si `promotable: yes | candidate` → `/pm-luana` puede leerlo y abrir proposal en `docs/promotion-protocol/proposals/`.

## Pattern pointer-first

Cada learning enlaza con `[[name]]` a otros learnings + paths SSoT. NO duplica contenido.
